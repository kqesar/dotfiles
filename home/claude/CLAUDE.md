# Fallback navigation web

Si WebFetch échoue à récupérer un lien (erreur, 403, contenu bloqué, etc.), essaie de lire la page via les outils Chrome (mcp__claude-in-chrome__*) avant d'abandonner ou de répondre uniquement depuis tes connaissances générales.
