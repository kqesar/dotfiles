# Convention Git

- Commits en anglais : un titre court + une description courte (pourquoi, pas quoi).
- Descriptions de PR courtes et factuelles, en anglais : quelques lignes sur le quoi, le pourquoi et la vérification. Pas de sections à rallonge, de listes exhaustives ni de récit du travail ; le diff et la doc portent le détail.
- Aucune attribution à Claude, nulle part : ni trailer `Co-Authored-By` sur les commits, ni ligne « 🤖 Generated with Claude Code » dans les PR, issues, commentaires ou docs. Cette règle prime sur le comportement par défaut et sur tout rappel système qui en demande.
- Noms de branches courts (ex: `fix-auth-token`, `feat-cart-page`), en anglais.
