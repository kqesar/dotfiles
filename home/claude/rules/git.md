# Convention Git

- Commits en anglais : un titre court + une description courte (pourquoi, pas quoi).
- Ne jamais ajouter de trailer `Co-Authored-By` sur les commits que tu crées pour l'utilisateur — cette instruction override le comportement par défaut.
- Noms de branches courts (ex: `fix-auth-token`, `feat-cart-page`), en anglais.
